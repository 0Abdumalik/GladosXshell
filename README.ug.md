# GladosXshell

[English](README.md) | [中文](README.zh.md) | ئۇيغۇرچە

GladosXshell — Windows ئۈچۈن SSH خېرىدار پروگراممىسى. تېرمىنال، ھۆججەت، مۇلازىمېتىر ھالىتى ۋە ئېغىز يوللاش بىر كۆزنەكتە بولۇپ، ئورۇنلاشتۇرۇلۇشى FinalShell غا يېقىن. كۆرۈنمە يۈز خەنزۇچە، ئىنگلىزچە ۋە ئۇيغۇرچە (ئوڭدىن سولغا) ئۈچ تىلدا.

نۆۋەتتىكى نەشرى 0.1.1 Beta.

## ئىقتىدارلار

- **ئۇلىنىش:**
  - SSH: ئىم، شەخسىي ئاچقۇچ، كۇنۇپكا تاختىسى ئارقىلىق ۋە ssh-agent / Pageant بىلەن كىرىش.
  - Telnet ۋە تەرتىپلىك ئېغىز.
  - ئۆتكۈنچى مۇلازىمېتىر، SOCKS5 ۋە HTTP ۋاكالەتچى.
  - تۇنجى قېتىم ئۇلانغاندا ئاساسىي ماشىنىنىڭ بارماق ئىزى تەكشۈرۈلىدۇ.
- **ئەكىرىش:** `~/.ssh/config`، Xshell، PuTTY ۋە FinalShell دىن ئۇلىنىش ئەكىرگىلى بولىدۇ.
- **يەرلىك تېرمىنال:** cmd، PowerShell، Git Bash ۋە WSL تارقىتىلمىلىرىنى ئۆزى تاپىدۇ. تېرمىنالنى بۆلۈپ كۆرسەتكىلى بولىدۇ.
- **بۇيرۇق بالدىقى:**
  - تېرمىنالنىڭ ئاستىدا تۇرىدۇ، بۇيرۇق تولۇقلاش ۋە تارىخ بىلەن.
  - ئورتاق كىرگۈزۈش بىلەن بىر كىرگۈزۈشنى بىر نەچچە تېرمىنالغا تەڭ ئەۋەتكىلى بولىدۇ.
  - دائىملىق بۇيرۇقلارنى «بۇيرۇقلار» تاختىسىغا ساقلاپ، بىر چېكىپلا ئىجرا قىلغىلى بولىدۇ.
- **ھۆججەت:**
  - SFTP ئارقىلىق كۆرۈش، يۈكلەش ۋە چۈشۈرۈش، يەتكۈزۈش ئۆچىرىكى بىلەن.
  - ZMODEM (rz / sz).
  - يىراقتىكى ھۆججەتنى ئىچكى تەھرىرلىگۈچتە ئاچقىلى بولىدۇ. ئۇنىڭدا گرامماتىكا رەڭلەش، ئىزدەش ۋە ئالماشتۇرۇش بار.
  - تېرمىنالدا قايسى قىسقۇچقا cd قىلسىڭىز، ھۆججەت تاختىسى شۇ قىسقۇچقا ئەگىشىدۇ.
- **ھالەت:**
  - مۇلازىمېتىرنىڭ CPU، ئىچكى ساقلىغۇچ، دىسكا، تور، كېچىكىش ۋە جەريانلىرى.
  - ئايرىم ئالىي ھالەت كۆزنىكى ۋە جەريان باشقۇرۇش.
- **ئېغىز يوللاش:** نۆۋەتتىكى ئەڭگىمىنىڭ يوللاشلىرى ۋە ئېقىمىنى كۆرسىتىدۇ. <bdi>`-L`</bdi> / <bdi>`-R`</bdi> / <bdi>`-D`</bdi> يوللاشنى ۋاقتىنچە قوشقىلى بولىدۇ.
- **Docker ۋە Kubernetes:** مۇلازىمېتىردىكى قاچا ۋە Pod لارنى كۆرۈش ۋە باشقۇرۇش.
- **تېرمىنال ياردەمچىلىرى:**
  - ماكرو: بىر قاتار كىرگۈزۈشنى خاتىرىلەپ قايتا قويىدۇ. ئارىدا مەلۇم چىقىرىشنى كۈتۈپ تۇرغۇزغىلىمۇ بولىدۇ.
  - قوزغاتقۇچ: چىقىرىش ماس كەلگەندە گەۋدىلەندۈرىدۇ، ئەسكەرتىدۇ ياكى كىرگۈزۈش ئەۋەتىدۇ.
  - ئەڭگىمىنى asciicast فورماتىدا خاتىرىلەش ۋە قايتا قويۇش.
  - خاتىرە گەۋدىلەندۈرۈش: ERROR، WARN، INFO ۋە IP ئادرېسلىرىنى رەڭلەيدۇ.
- **ئاچقۇچ ۋە بىخەتەرلىك:**
  - ئاچقۇچ ئامبىرى: SSH ئاچقۇچى ھاسىل قىلىدۇ ۋە ئەكىرىدۇ. ئاممىۋى ئاچقۇچنى بىر قەدەمدىلا مۇلازىمېتىرغا ئورنىتىدۇ.
  - ساقلانغان ئىملار كۆڭۈلدىكى ھالەتتە Windows DPAPI بىلەن مەخپىيلەشتۈرۈلىدۇ. ئاساسىي ئىم بەلگىلىسىڭىز، ئۇنىڭ ئورنىغا ئاساسىي ئىم بىلەن مەخپىيلەشتۈرۈلىدۇ.
  - تەڭشەك ۋە ئۇلىنىشلارنى ئىم بىلەن قوغدالغان زاپاس قىلىپ چىقارغىلى بولىدۇ.
- **كۆرۈنۈش:**
  - ئۈچ خىل ئورۇنلاشتۇرۇش. تاختىلارنى ئوخشىمىغان رايونلارغا سۆرەپ يۆتكىگىلى بولىدۇ.
  - قېنىق ۋە سۇس ئۆرنەك.
  - تېرمىنال خەت نۇسخىسى، تەگلىك رەسىمى ۋە ئىختىيارى CSS.
- **قىستۇرما:**
  - ئىچكى ئىقتىدارلارنىڭ ئۆزىمۇ قىستۇرما، ھەربىرىنى ئايرىم چەكلىگىلى بولىدۇ.
  - ئۈچىنچى تەرەپ قىستۇرمىلىرى JavaScript دا يېزىلىدۇ ۋە ئايرىۋېتىلگەن مۇھىتتا ئىجرا بولىدۇ. ئۇلار سورىغان ھوقۇقلارنى ئىشلەتكۈچى رۇخسەت قىلىدۇ.

## ئورنىتىش

`GladosXshell-Setup-<نەشر>.exe` نى ئىجرا قىلىڭ. نۆۋەتتىكى ئىشلەتكۈچىگە ياكى بارلىق ئىشلەتكۈچىلەرگە ئورنىتىشنى تاللاڭ، ئاندىن ئورنىتىش ئورنىنى تاللاڭ. ئۆچۈرگەندە سانلىق مەلۇماتنى ساقلاپ قېلىش ياكى ئۆچۈرۈشنى تاللىغىلى بولىدۇ.

- **سىستېما تەلىپى:** 64 بىتلىق Windows 10 / 11 ۋە WebView2 ئىجرا مۇھىتى. Windows 11 ۋە يېڭىراق Windows 10 دا ئۇ بار.
- **سانلىق مەلۇمات ئورنى:** <bdi>`%USERPROFILE%\.gladosxshell`</bdi>.
- **ئېلىپ يۈرۈشچان ئىشلىتىش:** `gladosxshell.exe` نىڭ يېنىدا `data` قىسقۇچى قۇرسىڭىز، سانلىق مەلۇمات شۇ يەردە ساقلىنىدۇ.
- **كۆرۈنمە يۈز تىلى:** «تەڭشەك ← كۆرۈنۈش» تە تاللاڭ. قايتا قوزغالغاندىن كېيىن كۈچكە ئىگە بولىدۇ. كۆڭۈلدىكىسى «Windows غا ئەگىشىدۇ».

تېزلەتمە كۇنۇپكىلار:

| مەشغۇلات | كۇنۇپكا |
|---|---|
| بۇيرۇق تاختىسى | <bdi>`Ctrl+Shift+P`</bdi> |
| ئۇلىنىش باشقۇرغۇچ | <bdi>`Ctrl+Shift+N`</bdi> |
| تەڭشەك | <bdi>`Ctrl+,`</bdi> |

## قىستۇرما ئېچىش

ئەپ ئىچىدىكى «قىستۇرما ئېچىش قوللانمىسى» تىزىملىك ھۆججىتى (plugin.json)، ھوقۇقلار ۋە پۈتۈن API نى تونۇشتۇرىدۇ. ئۇنى بۇيرۇق تاختىسىدىن «قىستۇرما ئېچىش قوللانمىسى» نى ئىزدەپ ئاچقىلى بولىدۇ.

- **تىپ ئېنىقلىمىلىرى:** [sdk/gx.d.ts](sdk/gx.d.ts).
- **مىساللار:** [examples/plugins](examples/plugins).
  - `hello` بۇيرۇق، تىزىملىك، ھالەت بالدىقى ۋە تاختىنى كۆرسىتىدۇ.
  - `disk-alert` مۇلازىمېتىردا `df` نى ۋاقتى-ۋاقتىدا ئىجرا قىلىپ، دىسكا تولاي دېگەندە ئاگاھلاندۇرىدۇ.
- **تەرجىمە:** قىستۇرما ئۆز نامى ۋە ماۋزۇلىرىنى `plugin.json` دىكى `locales` ئارقىلىق تەرجىمە قىلىدۇ. ئىجرا ۋاقتىدا كۆرۈنمە يۈز تىلىنى `gx.lang` دىن ئوقۇيدۇ.

## قۇرۇش

Node.js ۋە مۇقىم نەشرىدىكى Rust (edition 2024) كېرەك.

</div>

```sh
npm install
npm run tauri dev        # ئېچىش ھالىتىدە ئىجرا قىلىش
npm run check            # Biome، TypeScript، Vitest، تەرجىمە قىلىنمىغان تېكىست تەكشۈرۈش
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
npm run build:release    # رەسمىي نەشر ئورناتقۇچى
npm run build:debug      # سىناق نەشرى ئورناتقۇچى (ئاچقۇچىلار قورالى بار، سانلىق مەلۇمات ئايرىم ساقلىنىدۇ)
```

<div dir="rtl">

ئورناتقۇچلار <bdi>`target/release/setup/`</bdi> قىسقۇچىغا چىقىرىلىدۇ.

كود قۇرۇلمىسى:

| قىسقۇچ | مەزمۇنى |
|---|---|
| <bdi>`src/`</bdi> | ئالدى ئۇچ (TypeScript + Vite) |
| <bdi>`crates/gxs-core/`</bdi> | ئۇلىنىش، دەلىللەش، سانلىق مەلۇمات ۋە ئاچقۇچ (Rust) |
| <bdi>`src-tauri/`</bdi> | ئەپ قېپى |
| <bdi>`installer/`</bdi> | ئورناتقۇچ |

يېڭى قوشۇلغان كۆرۈنمە يۈز تېكىستلىرىگە `zh`، `en` ۋە `ug` نىڭ ھەممىسى يېزىلىشى كېرەك.

## سۇپا

ھازىرچە پەقەت Windows نىلا قوللايدۇ. كودتا Linux ۋە macOS ئۈچۈن تارماقلار بار، ئەمما بۇ ئىككى سىستېمىدا تېخى قۇرۇلۇپ سىنالمىدى. ئۇنىڭ ئۈستىگە ئاساسىي ئىم بەلگىلەنمىگەندە، ئىم ساقلاش Windows DPAPI غا تايىنىدۇ.
